GitHub Desktop for LinuxGitHub Desktop pour Linux

Package repository for the maintained Linux builds. Add it once, then upgrade with the rest of your system.

Dépôt de paquets des versions Linux maintenues. Ajoutez-le une fois, puis mettez à jour avec le reste de votre système.

Choose a channelChoisir un canal

Pick one. Your package manager then keeps you on the newest version of that channel by itself, with no download to repeat.

Choisissez-en un. Votre gestionnaire de paquets vous garde ensuite de lui-même sur la version la plus récente de ce canal, sans téléchargement à refaire.

Most of the time stable and latest hold the same version. They differ after a new release, until it has been proven.

La plupart du temps, les canaux stable et latest contiennent la même version. Ils diffèrent après une nouvelle sortie, jusqu'à ce que celle-ci ait fait ses preuves.

Debian, Ubuntu, Linux Mint, Pop!_OS

Add the signing key once, whichever channel you pick:

Ajoutez la clé de signature une seule fois, quel que soit le canal choisi : 

curl -fsSL https://packages-github-desktop.nitramo.fr/gpg.key \
  | sudo gpg --dearmor -o /usr/share/keyrings/github-desktop.gpg

Then, for the stable channelPuis, pour le canal stable 

echo "deb [arch=amd64 signed-by=/usr/share/keyrings/github-desktop.gpg] \
https://packages-github-desktop.nitramo.fr/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/github-desktop.list

sudo apt update && sudo apt install github-desktop

For the latest channelPour le canal latest 

echo "deb [arch=amd64 signed-by=/usr/share/keyrings/github-desktop.gpg] \
https://packages-github-desktop.nitramo.fr/deb latest main" \
  | sudo tee /etc/apt/sources.list.d/github-desktop.list

sudo apt update && sudo apt install github-desktop

For the beta channelPour le canal beta 

echo "deb [arch=amd64 signed-by=/usr/share/keyrings/github-desktop.gpg] \
https://packages-github-desktop.nitramo.fr/deb beta main" \
  | sudo tee /etc/apt/sources.list.d/github-desktop.list

sudo apt update && sudo apt install github-desktop

Fedora, RHEL, Rocky, AlmaLinux

Import the signing key once, whichever channel you pick:

Importez la clé de signature une seule fois, quel que soit le canal choisi : 

sudo rpm --import https://packages-github-desktop.nitramo.fr/gpg.key

Then, for the stable channelPuis, pour le canal stable 

sudo curl -fsSL -o /etc/yum.repos.d/github-desktop.repo \
  https://packages-github-desktop.nitramo.fr/rpm/stable/github-desktop.repo

sudo dnf install github-desktop

For the latest channelPour le canal latest 

sudo curl -fsSL -o /etc/yum.repos.d/github-desktop.repo \
  https://packages-github-desktop.nitramo.fr/rpm/latest/github-desktop.repo

sudo dnf install github-desktop

For the beta channelPour le canal beta 

sudo curl -fsSL -o /etc/yum.repos.d/github-desktop.repo \
  https://packages-github-desktop.nitramo.fr/rpm/beta/github-desktop.repo

sudo dnf install github-desktop

Changing channel laterChanger de canal plus tard

Replace the file you created and update: on Debian and friends /etc/apt/sources.list.d/github-desktop.list, on Fedora and friends /etc/yum.repos.d/github-desktop.repo. There is one file and one package name, so a machine follows one channel at a time.

Remplacez le fichier que vous avez créé, puis mettez à jour : sur Debian et ses dérivées /etc/apt/sources.list.d/github-desktop.list, sur Fedora et ses dérivées /etc/yum.repos.d/github-desktop.repo. Il n'y a qu'un fichier et qu'un nom de paquet : une machine suit donc un seul canal à la fois.

Moving down a channel, from beta to stable for instance, means removing the package first: the version you already have is the higher one, and package managers refuse to go backwards on their own.

Descendre d'un canal, de beta vers stable par exemple, oblige à désinstaller d'abord le paquet : la version déjà installée est la plus élevée, et les gestionnaires de paquets refusent de revenir en arrière d'eux-mêmes.
